# AgriTech MERN

## Run
1. Backend: `cd server && npm install && cp .env.example .env` (fill values) `&& npm run dev`
2. Frontend: `cd client && npm install && cp .env.example .env && npm start`
3. Open http://localhost:3000, register (farmer). To make an admin, set `role: "admin"` on that user in MongoDB.
